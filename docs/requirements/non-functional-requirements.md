# Non-functional Requirements

| ID | Area | Requirement |
|---|---|---|
| NFR1 | Performance | Home page loads in about 3 seconds on a normal connection |
| NFR2 | Compatibility | Works on phone, tablet, and desktop (responsive) |
| NFR3 | Usability | Order in 5 steps or fewer; clear error messages |
| NFR4 | Security | Protected customer and admin routes; hashed passwords in the real backend; card data is never stored |
| NFR5 | Reliability | The cart is not lost on refresh |
| NFR6 | Maintainability | Small components, clear names, consistent formatting (Prettier) |
| NFR7 | Documentation | API paths are documented and match the implementation |
