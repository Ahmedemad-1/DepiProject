# Functional Requirements

- FR1: Browse the menu by category, search, and filter.
- FR2: View dish details and choose size and extras.
- FR3: Manage the cart (add, remove, change quantity) and keep it after refresh.
- FR4: Register, log in, and log out.
- FR5: Place a pickup order with a pickup time and payment method (cash or demo card).
- FR6: Track order status and see previous orders.
- FR7: Reserve a table and see the reservation status.
- FR8: Admin adds, edits, deletes dishes and sets availability.
- FR9: Admin changes order status and confirms or cancels reservations.
- FR10: The API stores data in a database and protects admin endpoints.
