# Risk Assessment and Mitigation

| Risk | Impact | Mitigation |
|---|---|---|
| Learning React while building | Delays | Learn the 4 core concepts first; start with static pages |
| Backend delay | Frontend blocked | Frontend uses json-server with the same API contract |
| Real backend differs from the mock API | Bugs when connecting | Follow `docs/api.md`; record any difference there immediately |
| AI-generated code nobody understands | Cannot fix or explain it | Read every line; explain it to a teammate before merging |
| Merge conflicts | Lost work | One branch per feature; Pull Request for every merge |
| Not enough time | Features unfinished | Cut list: promo code, ratings, favorites, language toggle, order tracking; the main flow is never cut |
| A team member unavailable | Part of the project blocked | Everyone documents their work and explains it to someone else |
| Lost mock data | Menu lost | `db.json` is stored in GitHub |
