# Images

Every file here is a PLACEHOLDER picture. Replace each one with a real photo using the **same file name**
(for example `margherita-pizza.jpg`), and the site updates without any code change.

| File | Used by |
|---|---|
| `<dish-slug>.jpg` (32 files, names come from the `image` field in `server/mock/db.json`) | Menu, Home, DishDetails, Cart, admin pages |
| `hero.jpg` | Home page banner |
| `about.jpg` | About page |
| `placeholder.jpg` | fallback shown when a dish photo is missing |

Tips: use free photos (Unsplash, Pexels), around 800 x 600 px, JPG under 200 KB each (compress them first).
If you add a new dish in `db.json`, add its photo here with the name written in its `image` field.
